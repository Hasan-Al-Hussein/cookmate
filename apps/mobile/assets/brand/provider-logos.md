# Account provider marks

Retrieved 1 October 2026 for CookMate's account sign-in controls.

- `google-g.png`: unchanged 200 × 204 provider asset from https://developers.google.com/static/identity/images/g-logo.png. Keep its original colours and aspect ratio. Local PNG is used because Google's current SVG export uses `foreignObject`/conic gradients unsupported by the native SVG renderer.
- Apple path in `src/features/account/ProviderSignInButton.tsx`: unmodified logo path from Apple's Sign in with Apple JavaScript, https://appleid.cdn-apple.com/appleauth/static/jsapi/appleid/1/en_US/appleid.auth.js. Render proportionally in monochrome.

Provider references:
- https://developers.google.com/identity/branding-guidelines
- https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple

These marks identify the existing account actions; they do not indicate that a provider has been configured or that sign-in is available.
